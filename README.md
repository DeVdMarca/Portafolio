# 🧠 OrgaTime // Cybernetic AI Portfolio

Un portafolio web interactivo tridimensional en **Three.js** con un ecosistema de diseño futurista, simulación de fallos del sistema y una interfaz de **síntesis de voz reactiva** nativa (Web Speech API).

## 🚀 Características Principales

*   **Lienzo 3D Cuántico:** Sistema de 2,500 partículas animadas en Three.js con físicas suaves y respuesta de inercia al movimiento del mouse.
*   **Audio Reactivo Avanzado:** Ecualizador gráfico en tiempo real conectado mediante variables CSS directamente a la modulación de voz de la IA.
*   **Efectos Mecatrónicos:** Secuencias dinámicas de cortocircuito, distorsión (*glitch*) y simulación de fallos de terminal al cambiar de sección.
*   **Navegación Fluida:** Transición espacial tridimensional entre los sub-espacios del núcleo (`/SobreMí`, `/Proyectos`, `/Stack`, `/AnalizarOperador`).

## 🛠️ Tecnologías Utilizadas

*   **Three.js** (Motor de renderizado 3D para el universo de partículas)
*   **Web Speech API** (Síntesis de voz nativa del navegador)
*   **HTML5 & CSS3** (Variables dinámicas de volumen, animaciones de barrido e interfaz HUD)
*   **JavaScript (ES6+)** (Lógica de control asíncrona, bucle analítico estocástico y transiciones)

## 📁 Estructura del Proyecto

```text
├── index.html       # Estructura HUD y contenedores de los nodos
├── style.css        # Reglas de estilo del escáner, widget de voz y animaciones
└── app.js           # Lógica del motor 3D, navegación y síntesis reactiva
```

## 🤖 Inicialización Automática

Debido a las políticas de seguridad de *Autoplay* de los navegadores modernos, la interfaz requiere una interacción inicial. El proyecto incluye un módulo de arranque virtual (`#splah-core-boot`). Al hacer clic en **`[ INICIAR_SISTEMA_CORE ]`**, el navegador desbloquea los canales de audio y la IA ejecuta la telemetría cuántica vocalizada de inmediato.
